# Guides

> En personlig samling af guides: hver guide, der deles med ejeren, klones og gemmes her og gøres tilgængelig fra en GitHub Pages-forside.

> **Status i Paperclip:** `planned` · **Repo:** [github.com/qvisty/Guides](https://github.com/qvisty/Guides) · Del af ClipCores mission om nyttige, lav-kompleksitets digitale produkter.

---

## Formål og vision

Formålet er at have ét fast sted, hvor guides, som ejeren får delt (fx via links), bliver bevaret og gjort let tilgængelige. I stedet for at være afhængig af eksterne links, der kan forsvinde, klones hver guide ind i dette repo og præsenteres fra en samlet forside.

Visionen: en GitHub Pages-forside, hvor hver delt guide får sit eget "område" med et link til den gemte guide (evt. med undersider). Så bygges der løbende et personligt, varigt bibliotek af nyttig viden.

## Slutmål (Definition of Done)

- En GitHub Pages-forside, der viser alle gemte guides som separate områder.
- En enkel, gentagelig proces: modtag link → klon/gem guide i repoet → tilføj område på forsiden.
- Ingen tab af indhold, selv hvis den oprindelige eksterne kilde forsvinder.

## Planlægning og faser

- ✅ **Fase 1 — Repo etableret + første guide gemt.**
- 🔧 **Fase 2 — GitHub Pages-forside:** Opsæt Pages og byg en forside, der lister gemte guides.
- ⬜ **Fase 3 — Områdestruktur:** Hver guide får sit eget område/afsnit med link (og evt. undersider).
- ⬜ **Fase 4 — Rutine:** Fast, let proces for at tilføje nye delte guides løbende.
