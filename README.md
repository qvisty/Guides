# Guides

Praktiske guider til AI-implementering i virksomheder — hooks, integrationer, prompts og rolle-baserede agent-pakker.

## Indhold

- [The AI Operations Starter Pack](the-ai-operations-starter-pack.md) — 28 hooks, 12 integrationer, 15 prompts og 4 rolle-baserede agent-pakker til mid-market teams
- [The Automation Playbook for Claude](the-automation-playbook-for-claude.md) — 20 Claude-skills i fem stadier (Map, Score, Build, Deploy, Prove), der tager ét workflow fra idé til dokumenteret ROI

## Skills

De 20 skills fra Automation Playbook-guiden ligger i [`.claude/skills/`](.claude/skills/) — én mappe per skill, klar til brug i Claude Code i dette repo. Se [skills-README'en](.claude/skills/README.md) for stadierne og brugen.
